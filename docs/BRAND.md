# Epiton brand brief

- **Name:** Epiton
- **Promise:** Tryton-compatible power with a modern, adaptive client
- **Voice:** precise, calm, technical — not playful ERP kitsch
- **Login hero:** brand name is the primary signal; one subtitle; one connect form
- **Palette:** deep ink `#0f1419`, mint accent `#3dd6c6`, ember `#f0a05a`, paper light `#f6f1e8`
- **Type:** Fraunces (display) + Sora (body)
- **Motion:** soft shell transitions only; no decorative noise
